I gave vox run in mOMonadOS the same two capabilities I just added to the standalone Vox binary: running a saved .imasm module directly, and falling back to a binary's own entry point when no symbol is given.

A .imasm file now carries its own symbol table, so vox run reads it as text and resolves symbols from that table with no second read of the original binary. And since a PE loader never builds a symbol table at all, a bare vox run <file> with no symbol now runs from the module's own entry point instead of demanding a name that a .exe can never supply.

Verified inside mOMonadOS's own REPL against a minimal static ELF whose _start calls exit(42) directly: entry(...) called exit(42) in 5 steps, matching the standalone Vox binary's result exactly. Full suite still at 262 passed, 0 failed.
