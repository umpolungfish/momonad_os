≺ now applies the real trilattice involution to the stack, not just its existing register-0 decrement. Its own table entry in the Imscriber's Guide names it exactly: "reverse morphism (involution T↔F, t↔f)" — a real transformation, unlike ≻, ⋈, and ⊙, which the same guide's gate table says carry the value through unchanged. Before this, ≺ never touched the stack at all, so a value entering it came out identical, which is precisely the "carry" behavior the guide reserves for the other three, not what it names for ≺ itself.

The fix is additive: the stack's top value gets popped, run through the real invol() from imasm_core's Reg16_3, and pushed back; the pre-existing register-0 decrement is untouched, since it operates on separate state. B and N are invol's fixed points, so most existing uses of ≺ where the value was already B or N see no change; a pure T or F now genuinely flips, which the old code could never produce.

Two new tests, one showing a fixed point holds and one showing a real flip that the old code could not have given. Full suite holds at 267 passed, 0 failed: the existing 265 plus these two.
